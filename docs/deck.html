Actionability

Every action is something a county or health center can start on Monday

Referral · County + university hospital (YTA)

Standardised 'suspicion of cancer' referral with direct access to diagnostics

  • Owner: county medical director + referral unit
  • First 90 days: agree on criteria for the top-5 cancers, add a 48-hour triage flag, open direct imaging slots
  • KPI: ≥ 90% triaged within 2 days; referral → test ≤ 14 days
  • Roadmap: 2.5.2, 3.1.2 · Evidence: Danish cancer patient pathways (BMC Cancer 2015)

Built into every action:

  • the measured gap that triggered it
  • an owner (role), 3 first steps and a KPI
  • the national roadmap action it delivers
  • peer-reviewed or official evidence, verified
  • an effort estimate

Includes Finnish evidence, e.g. the HPV self-sampling trial for screening non-attenders (Int J Cancer 2011).

Data quality & transparency

Built so a decision-maker can trust it, and so a judge can check it

Sourced

Source badge on every number. Reproducible ETL from the THL REST API. Strategy facts cited by page.

Honest

Robust vs possible gaps. Small-number flags. A limitations page. No "lives saved" claims without data.

Guarded AI

Gemini only sees cited facts. Any number missing from the source data is flagged. A rule-based fallback means the demo never breaks.

Public aggregate data only, no patient data · MIT licensed · Next.js, d3-geo, Google Gemini API
